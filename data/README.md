# Data Sources and Documentation

This project combines grocery purchasing data, household income estimates and geographical information to investigate nutrient diversity across London.

## 1. Tesco Grocery 1.0 Dataset

- **Source:** [Tesco Grocery 1.0 – Figshare](https://figshare.com/collections/Tesco_Grocery_1_0/4769354)
- **Research publication:** Aiello et al. (2020), *Scientific Data*.
- **Usage:** Grocery purchasing and nutrient diversity analysis.
- **Data availability:** The original dataset is not redistributed in this repository.

## 2. Household Income Estimates

- **Local filename:** `Net_income_bhc_equivalised.csv`
- **Likely source:** ONS Small Area Income Estimates (exact release not confirmed).
- **Geographical level:** Middle Layer Super Output Areas (MSOAs).
- **Number of records:** 7,201.
- **Main variable:** Net weekly income (£).
- **Additional variables:** Upper confidence limit, lower confidence limit and confidence interval.
- **Reference period:** Not yet verified.
- **Exact income definition:** Not yet verified against the original publication.
- **Licence:** Not yet verified.

Potential source documentation:

Original datasets are not redistributed through this repository.
